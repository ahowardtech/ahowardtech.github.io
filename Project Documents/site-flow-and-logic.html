Internal reference

HowardTech site flow and logic

A plain-language map of how howardtech.solutions works—from a visitor opening the site through hosting, navigation, contact submission, and deployment.

Last updated: August 1, 2026

1. Visitor and delivery flow

Visitor opens the domain

A browser requests https://howardtech.solutions.

Namecheap DNS routes the request

The root-domain ALIAS points to ahowardtech.github.io. The www CNAME points there too.

GitHub Pages serves the site

GitHub verifies the custom domain, provides the HTTPS certificate, and serves the site through its CDN.

Browser loads the Vite application

The browser receives the static HTML, CSS, JavaScript, and assets. React then renders the interactive site.

2. Application structure

React + TypeScript

Renders the site interface and handles interactions in the browser.

Vite

Builds source files into optimized static files in dist/.

Tailwind CSS

Provides the responsive layout, color system, spacing, and component styles.

Motion

Provides page and UI animations while respecting reduced-motion preferences.

3. React basics in this project

React builds the interface from small, reusable JavaScript functions called components. A component returns JSX, which looks like HTML but is written inside a .tsx file. React turns that JSX into the visible page.

src/main.tsx
  → finds the <div id="root"> in index.html
  → starts React
  → renders <App />

src/App.tsx
  → decides which page view to show
  → renders shared Navbar and Footer
  → passes data and actions to components
ConceptMeaning hereExample
ComponentA reusable piece of the interface.Navbar, Footer, ContactView, and ServicesView.
JSXHTML-like markup inside a TypeScript file.<ContactView /> tells React to render the contact-page component.
StateInformation React remembers while someone uses the site. When it changes, React updates the screen.currentView remembers the active page; menuOpen remembers whether the mobile menu is visible.
PropsData or functions a parent component gives to a child component.App gives Navbar an onNavigate function so a menu click can change the active page.
Event handlerCode that runs after a visitor action.A button's onClick can open the mobile menu or navigate to Contact.

React does not redraw the entire browser page for a menu click. It updates only the parts affected by changed state, such as the visible view or the mobile menu.

4. Page navigation logic

The site is a single-page application. It does not load a separate server page for Home, Services, Methodology, Contact, Privacy, or Terms.

Visitor actionWhat happensResult
Clicks a navigation linkThe URL hash changes, for example to #services.React changes the active view and scrolls to the top.
Opens the mobile hamburgerReact changes menuOpen to show the overlay menu.Visitors can choose a main page or a service capability.
Chooses a capabilityThe app opens Services, expands the selected service accordion, and scrolls to it.The visitor lands on the relevant service details.
Clicks Privacy Policy or TermsThe URL changes to #privacy or #terms.The appropriate basic legal view is shown.

5. Contact form logic

Visitor completes the form

Name, email, project details, service track, budget, and timeline are collected. Required fields are validated in the browser.

Browser submits to Formspree

The form data is sent over HTTPS to the configured Formspree endpoint. The site does not run its own backend.

Success or error state

A successful request shows an inquiry confirmation. A failed request shows a retry message.

The hidden _gotcha field is a honeypot used to discourage automated spam submissions.

6. Deployment flow

Code is pushed to main

The GitHub Actions workflow starts automatically.

GitHub Actions builds the site

The workflow installs dependencies and runs npm run build.

The dist/ artifact is uploaded

Vite includes content-hashed CSS and JavaScript assets plus files from public/.

GitHub Pages publishes the build

The CDN begins serving the new static site. New hashed assets avoid stale browser files.

Domain and GitHub Pages setup

This guide records how howardtech.solutions is served from GitHub Pages. Last updated August 1, 2026.

1. Namecheap DNS records

In Namecheap, open Domain List → Manage → Advanced DNS and maintain these host records:

TypeHostValuePurpose
ALIAS@ahowardtech.github.ioRoutes the apex domain to GitHub Pages.
CNAMEwwwahowardtech.github.ioRoutes www to GitHub Pages.
TXT_github-pages-challenge-vabssGitHub-provided verification valueConfirms domain ownership to GitHub.

Enter hostnames only—never prefix an ALIAS or CNAME value with https://. Keep the GitHub verification TXT record after verification.

2. Configure the custom domain in GitHub

  1. Open repository Settings → Pages.
  2. Set the custom domain to howardtech.solutions.
  3. Complete GitHub's TXT verification when prompted.
  4. After GitHub issues the certificate, enable Enforce HTTPS.

GitHub Pages manages the TLS certificate. Certificate provisioning can take several minutes after verification and DNS propagation.

3. Preserve the custom domain in deployments

The repository includes public/CNAME with howardtech.solutions. Vite copies it into the production dist/ folder, allowing every GitHub Pages deployment to retain the custom-domain association.

4. Deploy the site

A push to main triggers .github/workflows/deploy.yml. GitHub Actions installs dependencies, runs npm run build, uploads dist/, and deploys it to GitHub Pages.

GitHub Pages serves the site through its CDN. Vite content-hashes production assets, so new builds receive new asset URLs and do not require manual cache invalidation.
